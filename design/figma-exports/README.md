# Shopera UI design in Figma

I designed Shopera's marketplace interfaces for desktop and mobile in Figma. These boards showcase that design work across the project; the Seller frontend is my separate primary development responsibility.

## Image locations

Place the original exports in this directory using these exact filenames:

- `shopera-desktop-ui.png` — desktop marketplace UI design board.
- `shopera-mobile-ui.png` — mobile UI design board and responsive/mobile design direction.

Neither PNG is included yet. Do not substitute application screenshots for Figma boards or create empty image files.

## Enable the showcase

1. Add the real PNG exports at the paths above.
2. In the root README's **UI Design in Figma** section, remove the enclosing HTML comment for each supplied image and its caption. Remove the instructional sentence inside that comment as well.
3. Keep the image tags at `width="1200"` for a large board presentation, and check text readability on GitHub.
4. Commit the real exports and enabled references together in a separate commit.

The commented image tags already use the correct repository-relative paths. Until enabled, they do not render broken images publicly.
