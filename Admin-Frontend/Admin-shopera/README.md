# Shopera Admin frontend

Supporting team React/Vite application for administration. It is retained to preserve project context and workflows such as store approval; it is not presented as the portfolio owner's individual implementation.

See the [portfolio README](../../README.md), [contribution map](../../MY_CONTRIBUTION.md) and [setup guide](../../docs/SETUP.md).

Install locked dependencies with `npm ci`. Scripts: `npm run dev`, `npm run build`, `npm run lint`, and `npm test`. Authentication and live data require the supporting API and compatible database. The database SQL located here is not a complete bootstrap for all current backend features.
